# BLOCK MATRIX — Deluxe Gold Mobile Showcase

Open [mobile.html](./mobile.html) on the published showcase site. This standalone browser edition supports touch, mouse and keyboard.

The main menu has eight buttons in four rows. Use **Options** for mode and level choices, difficulty, music, UI Size, records, reset actions, control reference and gamepad status. Start displays the selected mode. Continue resumes an existing run while the page stays open.

The mobile controls remain available during gameplay: movement/rotation on the right and Drop/Hold/Pause/Help on the left beside the pit in wide landscape, with controls below the board in portrait. Hold movement arrows to repeat. Hold stores or swaps a piece once per placement. Next/Hold previews show the pieces. Popups dim and disable the controls.

Music defaults to ON; previously saved choices are retained. A tap or click may be required for sound. Fullscreen is optional and depends on the browser. Use the device browser if a social app's embedded browser causes problems.

Campaign starts at Level 1; Practice selects an excavation level; Free Play starts empty without excavation cells. The in-game guide explains the modes and block types.

Exit Game stops play and displays a message to close the browser tab. Local settings/records retain the existing mobile namespace and remain separate from desktop/Windows saves. They do not sync between devices. Clearing browser site data can erase them.

Upload mobile.html and README_Mobile.md beside desktop index.html; link to the exact lowercase mobile.html filename. Existing /mobile/ or /mobile/index.html links require their original files or an explicit link update. The ZIP is a delivery package; upload its extracted HTML and Markdown files.
