# BLOCK MATRIX — Deluxe Gold

A desktop and laptop browser showcase from **Deluxe Gold Studios**. Arrange falling pieces, clear complete rows and work through ten excavation sectors.

Play with a keyboard, a compatible gamepad, or the optional **mouse-operated on-screen controls**. The on-screen panel is designed for relaxed mouse play and also accepts touch input on touchscreen computers.

## Play

Open `index.html` in a modern browser, or visit the existing hosted showcase page. No installation, account, build command or Electron runtime is required.

Choose a mode and press its Start button:

- **Campaign:** always begins at Level 1. Complete the line target and clear every marked excavation cell to advance through ten sectors.
- **Practice Level:** select any of the ten excavation layouts and complete that sector's objectives.
- **Free Play:** starts with an empty pit, without excavation blocks. The selected level determines the starting speed and environment.

## On-screen controls

**On-Screen Controls and Music default to ON.** Both can be changed in the main-menu settings or in-game **Options**. **UI Size** sits beside On-Screen Controls.

The action group sits to the left of the pit and the movement group to the right on wide screens. Narrow windows place the controls below the pit. Controls remain outside the playfield, scale for larger displays, and dim and stop responding while a popup is open.

- Hold **Left**, **Right** or **Down** for repeated movement or soft drop.
- Click **Rotate**, **Drop** or **Hold** once for that action.
- **Pause** pauses play; **Help** opens How to Play.
- Keyboard and gamepad controls remain available while using the panel.

**Hold** saves the current piece for later, or exchanges it with the stored piece. You can use Hold once per piece placement. The HOLD preview shows the saved piece.

## Keyboard controls

| Key | Action |
| --- | --- |
| Left / Right arrows | Move |
| Down arrow | Soft drop |
| Up arrow / X | Rotate clockwise |
| Z | Rotate counterclockwise |
| Space | Hard drop |
| C | Hold / exchange piece |
| P | Pause / resume |
| O | In-game Options |
| M | Main menu |
| F | Fullscreen on / off |

For compatible gamepads, use the D-pad or left stick for movement, A/B to rotate, X/LB to Hold, Y/RB to hard drop, Start to pause and Back for the menu. Button labels can differ between controllers.

## Settings, records and display

Settings, progression and records are stored locally in the current browser profile. They do not automatically transfer between browsers, computers, the mobile showcase or the Windows application. Clearing browser site data can remove them.

Existing saved preferences take priority over the new ON defaults. Select **Restore Default Settings** to adopt the new defaults; this also resets the other options while keeping scores and progress. **Reset Everything** is a separate destructive action with a confirmation dialog.

Use **UI Size: Auto, Normal, Large or TV** to adjust interface readability, and **Full** to toggle fullscreen. The desktop layout supports laptop windows through 4K displays. This is the desktop edition; the separate mobile edition remains available at its existing showcase location.

Music may require a click or tap before the browser permits audio. Start the game and check the Music setting and browser/tab volume if it is silent.

## Updating the GitHub showcase

Replace the existing desktop showcase's `index.html` and `README.md` with these files in the same folder. Keep the filename `index.html` lowercase and preserve the existing folder path so current links continue to work. This update does not require changes to the mobile showcase.

After the published page refreshes, check the new controls and UI Size setting. If the browser shows the older page, reload without its cached copy. Previously saved OFF settings will remain OFF until changed or reset.
